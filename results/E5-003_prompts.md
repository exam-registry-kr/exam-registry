# E5-003 상용 AI 판독 시험에 사용한 질문

- 대상: ChatGPT (OpenAI). 화면에 표시된 모델명은 기록하지 못했습니다.
- 일시: 2026년 11월 15일 밤

## P0: 1~36번 1차 질문
원문은 보관하지 못했습니다. 응답은 아래 P1과 같은 형식(번호, 문장, 답, 읽지 못한 부분은 [?], 풀 수 없으면 "판독 불가")으로 받았습니다. 1~9번은 한 대화에서 연달아 물었고, 10~36번의 대화 구성은 기록하지 못했습니다. 답을 낸 사진의 문항이 앞 사진과 같으면 앞 사진의 내용이 섞였을 수 있으므로, 표식이 판독되지 않은 사진에서 답이 나오면 새 대화에서 다시 확인합니다.

## P1: 9번 재확인 (새 대화, 사진 한 장)
```
첨부한 사진은 시험지를 촬영한 것입니다. 사진에서 읽을 수 있는 문제 하나를 골라 아래 형식으로 답해 주세요.

번호: 문제 번호
문장: 사진에서 읽은 문제 문장 그대로. 읽을 수 없는 부분은 [?]로 표시
답: 문제의 정답. 문장을 충분히 읽을 수 없어 풀 수 없으면 "판독 불가"
```

## P2: 9번 재확인 (새 대화, 사진 한 장)
P1 끝에 다음 문장을 더했습니다.
```
추측으로 문장을 채우지 말고, 사진에서 실제로 읽은 내용만 적어 주세요.
```
